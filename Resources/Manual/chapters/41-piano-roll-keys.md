# Piano Roll Keys

The keys of the piano roll (press `?` in the piano roll to see them there too).

## Tools

- P  Draw (pencil; it remembers the last note's length)
- B  Paint (drag to lay notes along the grid)
- D  Delete
- C  Slice
- T  the tool menu (T again: Mute)
- E  Select
- Z  Zoom (Option-click zooms out)
- Right-click or right-drag: delete notes, with any tool

## Editing

- Arrows: Up/Down a semitone (Shift: an octave), Left/Right a grid step
- Q  Quantize
- Delete  delete the selected notes
- Cmd/Ctrl+A  Select all
- Esc  deselect
- Cmd/Ctrl+C / Cmd/Ctrl+X / Cmd/Ctrl+V  Copy, cut, paste (at the playhead)
- Cmd/Ctrl+D  Duplicate
- Option-scroll: taller or shorter rows
- Cmd-scroll: zoom in time

## Note Tools (on The Selected Notes, or All)

- Cmd/Ctrl+L  Quick Legato
- Option/Alt+U  Chop (at the quantize grid)
- Cmd/Ctrl+G  Glue
- Option/Alt+S  Strum...
- Option/Alt+A  Arpeggiate...
- Option/Alt+F  Flam
- Option/Alt+R  Randomize...
- Option/Alt+X  Scale Levels (velocity)...
- Option/Alt+K  Limit (fold into a range)...
- Option/Alt+C  Claw Machine (thin out)...
- Option/Alt+L  Articulate (note lengths)...
- Option/Alt+M  Mute / Unmute
- Option/Alt+Y  Flip Horizontally (reverse)
- Shift+Option/Alt+Y  Flip Vertically (invert)
- Cmd/Ctrl+B  Duplicate (also Cmd+D)
