# The manual

The in-app manual (Help > Manual, F1) and its PDF are made from this folder into `Resources/Manual/`:

1. Screenshots: `xvfb-run -a -s "-screen 0 2600x1500x24" Snapshots <shots>` (the full run, with the `*.layout.json`
   part positions), `Snapshots fx <shots>/fx <every effect type>` and `Snapshots nemix <shots>/nemix-synth "Supersaw Lead"`
   (and `nemix-sample "Grand Piano"`).
2. Facts: `Snapshots docsdump facts.json` (every command with its keys, every effect with its controls, Nemix's sounds).
3. Pictures: `python3 images.py <shots> ../../Resources/Manual/img` (numbered call-outs by annotate.py).
4. Chapters and PDF: `python3 build.py facts.json --pdf` (needs Python's markdown and playwright).

The hand-written chapters are in `chapters/`; effect descriptions in `effects.json`; the reference chapters (plugins,
Nemix sounds, recorded instruments, key commands) are generated by build.py. Check the manual window with
`AUDIOTECHPRO_MANUAL=Resources/Manual Snapshots manual <dir>`.
